# MSFT Safety Learning Report

A GitHub Pages-ready React simulation app for the fictional **Mary Seacole Foundation Trust**.

This build is the red full-screen MSFT version. It deliberately avoids the Datix name and uses **Safety Learning Report** instead.

## Publish on GitHub Pages

1. Upload this whole folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Set **Branch** to `main` and **Folder** to `/docs`.
5. Save.

The app runs from `docs/index.html` using React from CDN, so there is no terminal/build step.
