# MSFT Safety Learning Report

Use this build to replace the current blank page.

## What to upload

Upload these files/folders to the **root of your GitHub repository**:

- `docs/`
- `index.html`
- `.nojekyll`
- `README.md`

The app is duplicated in both:

- `/docs/index.html` for GitHub Pages set to `/docs`
- `/index.html` in case GitHub Pages is set to root

## GitHub Pages setting

Recommended:

- Source: Deploy from a branch
- Branch: main
- Folder: /docs

## Why this version should not be blank

This version has no external scripts, no React, no Babel, no CDN, no npm, and no separate CSS or JS files. The complete app is inside the HTML file itself, so the form is visible even before JavaScript runs.

This is a simulation-only safety learning report for Mary Seacole Foundation Trust. It is not Datix and is not connected to any live NHS system.
